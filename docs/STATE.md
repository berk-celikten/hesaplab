# Mevcut durum
- Aşama: React / JavaScript; ilk görev uygulandı, kullanıcı alıştırması bekleniyor.
- Repo kökü: çalışma klasöründeki BankFlow/; diğer kullanıcı dosyaları korundu.

## Tamamlananlar
- Vite React JavaScript kurulumu; App, Header, AccountList, AccountCard.
- Aynı Demo Müşteri 01 için iki hesap: 10.000,00 TL ve 3.000,00 TL.
- Props ve map ile sabit liste; mobil düzen için CSS medya sorgusu.
- State, giriş, transfer, API, Oracle ve RabbitMQ eklenmedi.
- README, çalışma kuralları, yol haritası ve gitignore hazır.

## Kontroller
- Node 24.19.0 / npm 11.17.0; Vite 8.3.5 motor gereksinimi uyumlu.
- npm install başarılı; kurulum raporunda 0 güvenlik açığı.
- npm run build ve npm run lint başarılı.
- Geliştirme sunucusu başladı; tarayıcı yerel adrese bağlanamadı.
- Masaüstü/mobil görsel doğrulama yapılamadı.
- GitHub bağlı hesap ve CLI: berk-celikten, ağ erişimiyle doğrulandı.

## Öğrenilecekler

- Alıştırma: Birikim Hesabı bakiyesini 3.500,00 TL yapıp değişen kartı kontrol et.
